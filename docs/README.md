# 文档

第一次复现先看 [操作指南](guides/README.md)。板卡路径、网卡名、串口名等保留原测试环境的配置，具体说明见各篇指南。

| 分类 | 内容 |
| --- | --- |
| [操作指南](guides/README.md) | 构建入口、镜像来源、双板启动与烧录、GDB、常用命令 |
| [历史问题与修复](history/README.md) | 板卡调试、串口、页表故障、多核迁移和验收记录 |
| [总结](summaries/README.md) | 应用适配总手册、开发困难、移植总结和阶段贡献 |
| [性能测试](benchmarks/README.md) | 六类性能测试的优化报告、评分脚本和测试结果 |
| [正式报告](reports/README.md) | 初赛、决赛、BuildStorm、现场赛的 Typst 工程和 PDF |
| [原始记录](evidence/README.md) | 已保存的运行日志和性能采样 |

同一主题的重复版本只保留较新的文档。初赛、决赛及不同专项的报告分别保留；测试结果是不同实验的数据，不按重复报告删除。Typst 工程内容未改。

历史报告中的版本、配置和成绩只代表当时的实验。部分原始日志未随仓库提供，相关引用仍保留。脚本已精简为五个，用途见 [scripts/README.md](../scripts/README.md)。历史文档中已删除的验收脚本可从 Git 历史查找。
