# 板卡操作指南

文档中的命令涉及具体的网卡、串口和磁盘设备名，无法统一使用通用设备名。
示例保留原测试环境的配置，请自行修改为测试所用电脑的对应设备名。

## 星光二号板（VisionFive 2）

- [启动指令](VF2开发板启动命令.md)：构建、TFTP 部署和手动启动。
- [烧录教程](星光二号板烧录教程.md)：通过读卡器写入 SD 卡指定分区，校验并扩容。

## 龙芯二号板（LS2K1000LA）

- [启动指令](2K1000LA板-启动指令.md)：构建、部署和启动。
- [烧录教程](龙芯二号板烧录教程.md)：`sdcard-la-pub.img.gz` 在宿主机缩容，烧录到 `/dev/sda2` 后扩容。
