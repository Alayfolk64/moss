# 常用命令

更新日期：2026-08-19

## 快速解压

最常用、参数最少且明确指定压缩格式的命令：

```bash
# .gz：解压单个文件，得到 file
gunzip file.gz

# .xz：解压单个文件，得到 file
unxz file.xz

# .tar.gz：解压归档到当前目录
tar -xzf archive.tar.gz

# .tar.xz：解压归档到当前目录
tar -xJf archive.tar.xz
```

例如，镜像文件可直接这样解压：

```bash
unxz alpine-linux-loongarch64-ext4fs.img.xz
```

解压后得到：

```text
alpine-linux-loongarch64-ext4fs.img
```

### 格式区别

- `.gz`、`.xz` 通常只压缩一个文件；使用 `gunzip`、`unxz`。
- `.tar.gz`、`.tar.xz` 可以包含多个文件和目录；使用 `tar`。
- `gunzip` 和 `unxz` 默认会删除原压缩文件；解压出的文件会保留。
- `tar` 解压后不会删除原压缩包。

### 需要保留原压缩文件

```bash
gunzip -k file.gz
unxz -k file.xz
```

### 解压到指定目录

目标目录必须先存在：

```bash
mkdir output
tar -xzf archive.tar.gz -C output
tar -xJf archive.tar.xz -C output
```

### 参数含义

- `-x`：解压。
- `-z`：处理 gzip 压缩。
- `-J`：处理 xz 压缩。
- `-f`：后面跟压缩包文件名。
- `-C`：解压到指定目录。
- `-k`：解压后保留原压缩文件。

## Alpine `apk` 包管理

下面以 `curl` 为示例包名。在 Alpine 的 root shell 中执行：

```sh
# 更新软件包索引，不会升级已经安装的软件包
apk update

# 搜索软件包
apk search curl

# 安装软件包
apk add curl

# 查看一个软件包的信息
apk info curl

# 列出已经安装的软件包
apk info

# 卸载软件包
apk del curl

# 升级所有已经安装的软件包
apk upgrade
```

一次安装多个软件包时，把包名依次写在后面：

```sh
apk add python3 py3-pip
```

不想保留下载缓存时：

```sh
apk add --no-cache curl
```

## 允许板卡网段通过宿主机防火墙

本文使用的板卡网段是 `192.168.88.0/24`。

### 允许板卡访问宿主机服务

这条规则允许板卡访问宿主机上的 HTTP、TFTP、SSH 等服务。命令先检查规则是否存在，
不存在时才添加，重复执行不会生成重复规则：

```bash
sudo iptables -C INPUT -s 192.168.88.0/24 -j ACCEPT || \
  sudo iptables -I INPUT 1 -s 192.168.88.0/24 -j ACCEPT
```

### 允许板卡通过宿主机访问公网

只访问宿主机上的 `/srv/tftp` 时不需要下面这些命令。需要让板卡借用宿主机的公网连接时执行：

```bash
# 开启 IPv4 转发
sudo sysctl -w net.ipv4.ip_forward=1

# 允许板卡发出的流量经过宿主机转发
sudo iptables -C FORWARD -s 192.168.88.0/24 -j ACCEPT || \
  sudo iptables -I FORWARD 1 -s 192.168.88.0/24 -j ACCEPT

# 允许公网响应流量返回板卡
sudo iptables -C FORWARD -d 192.168.88.0/24 \
  -m conntrack --ctstate RELATED,ESTABLISHED -j ACCEPT || \
  sudo iptables -I FORWARD 1 -d 192.168.88.0/24 \
    -m conntrack --ctstate RELATED,ESTABLISHED -j ACCEPT

# 对板卡流量做地址转换
sudo iptables -t nat -C POSTROUTING -s 192.168.88.0/24 -j MASQUERADE || \
  sudo iptables -t nat -A POSTROUTING -s 192.168.88.0/24 -j MASQUERADE
```

检查当前状态：

```bash
sysctl net.ipv4.ip_forward
sudo iptables -S INPUT
sudo iptables -S FORWARD
sudo iptables -t nat -S POSTROUTING
```

这些是当前运行时规则。没有使用 `iptables-persistent` 等持久化工具时，重启宿主机后需要重新添加。

## 离线同步板卡时间

宿主机时间正确时，在宿主机执行：

```bash
date -u '+busybox date -u -s %Y%m%d%H%M.%S'
```

这条命令不会直接修改板卡时间，而是输出一条可在板端执行的命令，例如：

```text
busybox date -u -s 202608191430.25
```

立即把输出的整行复制到板端 root shell 执行，然后检查：

```sh
busybox date -u -s 202608191430.25
date -u
```

- 第一个 `-u` 表示使用 UTC 时间。
- `-s` 表示设置系统时间。
- `%Y%m%d%H%M.%S` 依次表示年、月、日、时、分和秒。
- 这种方法只修改本次启动的系统时间；板卡重启后需要重新执行。
- 当前 MOSS 不支持用 `busybox hwclock -w -u` 写 RTC，因此不要把 `hwclock` 加入这套流程。
